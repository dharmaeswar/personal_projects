# Personal Projects — Dharma Eswar Tirumalasetti

Portfolio projects in quantitative model validation, derivatives pricing checks, and test automation. Each project is self-contained with its own README, source code, and pytest suite.

| Project | What it does |
| --- | --- |
| [cross-asset-model-validation-suite](cross-asset-model-validation-suite/) | Analytic invariant checks for interest-rate, FX, and equity pricing models, driven by YAML stress/scenario grids, with pass–fail summary reports. |
| [vol-surface-consistency-checker](vol-surface-consistency-checker/) | Arbitrage and consistency checks for implied-volatility surfaces: calendar and butterfly conditions, stale-quote detection, RMS smile error, instant alerts. |
| [monte-carlo-xva-benchmark](monte-carlo-xva-benchmark/) | Monte Carlo exposure simulation across asset classes producing EE/PFE profiles and CVA/FVA/KVA ladders, benchmarked against closed-form values within a tolerance band. |
| [model-validation-toolkit](model-validation-toolkit/) | Small Python toolkit for model validation work: outcomes analysis, sensitivity testing, and population drift checks. |
| [pytest-api-automation-framework](pytest-api-automation-framework/) | Pytest-based API test automation framework with a sample REST API and an end-to-end test suite. |
